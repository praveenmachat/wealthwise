Configure Google Sign-In

One-time setup · Takes about 5 minutes · Completely free

⚠️ This page helps you configure Google OAuth for your WealthWise deployment. You only need to do this once.
1

Go to Google Cloud Console

Open console.cloud.google.com and sign in with praveenmachat@gmail.com

2

Create a new project

  • Click the project dropdown at the top → New Project
  • Name: WealthWise → Click Create
  • Wait ~30 seconds for it to create, then select it
3

Configure OAuth consent screen

  • Go to APIs & Services → OAuth consent screen
  • Select External → Click Create
  • App name: WealthWise
  • User support email: praveenmachat@gmail.com
  • Developer email: praveenmachat@gmail.com
  • Click Save and Continue through all steps
4

Create OAuth credentials

  • Go to APIs & Services → Credentials
  • Click + Create Credentials → OAuth 2.0 Client ID
  • Application type: Web application
  • Name: WealthWise Web
  • Under Authorized JavaScript origins add:
    https://wealthwisemsp.netlify.app
    http://localhost (for local testing)
  • Click Create
  • Copy the Client ID (ends in .apps.googleusercontent.com)
5

Paste your Client ID here

Paste the Client ID you copied from Google Cloud Console:

✓ Copy this and replace line in your login.html:

Find YOUR_GOOGLE_CLIENT_ID in login.html and replace with the above value

6

Add test user (while in testing mode)

  • Go back to OAuth consent screen
  • Scroll to Test users → Click Add users
  • Add: praveenmachat@gmail.com
  • Click Save — now you can sign in with your Google account!
  • To allow all users: click Publish App (takes ~a few days for Google review)
✓

You're done!

Upload the updated login.html and auth.js to GitHub → Netlify auto-deploys. Your Google Sign-In button will appear on the login page.
