# WealthWise — Deployment Guide

## Files
- `index.html` — Landing website (rename wealthwise.html to index.html)
- `app.html`   — Finance app (to be added next)

## Free Hosting Options (recommended order)

### 1. Netlify (EASIEST — drag & drop, no account needed)
1. Go to https://netlify.com
2. Click "Deploy without signing up" or sign up free
3. Drag your folder onto the deploy area
4. Done! You get a URL like https://wealthwise-abc123.netlify.app

### 2. GitHub Pages (free, custom domain support)
1. Create a GitHub account at github.com
2. New repository → name it "wealthwise"
3. Upload index.html and app.html
4. Settings → Pages → Deploy from main branch
5. URL: https://yourusername.github.io/wealthwise

### 3. Vercel (fast, free)
1. Go to vercel.com
2. Import from GitHub or drag & drop
3. Instant deployment

### 4. Cloudflare Pages (fastest CDN)
1. Go to pages.cloudflare.com
2. Connect GitHub or direct upload
3. Free with unlimited bandwidth
